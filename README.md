# primate-niche-networks-Jurua
This repository contains the data and R scripts used in the paper "Hunting-driven defaunation reshapes niche partitioning networks in Amazonian primate communities".

Folder structure
- Data: input data used by the scripts. The subfolder Group_analysis contains the data for the group-level sensitivity analysis.
- Scripts: R scripts used for the analyses.
- Results: output tables and matrices generated by the scripts.
- Figures: output figures generated by the scripts.

Scripts
The scripts are numbered from 01 to 07 in the order in which they must be run.
